La protection de vos données personnelles est une priorité pour {{ config.nom_boutique if config else 'Kiosque Pro' }}. Cette politique explique comment nous collectons, utilisons et protégeons vos informations.

1. Données collectées

Dans le cadre de l'utilisation de nos services (Borne, Kiosque, WhatsApp), nous sommes susceptibles de collecter les données suivantes :

  • Données d'identification : Nom, prénom.
  • Données de contact : Numéro de téléphone, adresse email, adresse postale.
  • Données de transaction : Historique des paiements, factures Tasshilat, reçus.

2. Utilisation des données

Vos informations sont utilisées exclusivement pour :

  • Gérer vos dossiers et suivre vos paiements.
  • Vous envoyer des notifications de statut (ex: rappels de dette, monnaie disponible) via WhatsApp.
  • Générer des reçus et factures officiels.

3. Protection et Sécurité

Toutes les données sont stockées de manière sécurisée. L'accès à ces informations est strictement limité au personnel autorisé de {{ config.nom_boutique if config else 'notre établissement' }} disposant d'un compte sécurisé.

4. Vos droits

Conformément à la réglementation en vigueur sur la protection des données (notamment la loi 09-08 au Maroc), vous disposez d'un droit d'accès, de rectification et de suppression de vos données. Pour exercer ce droit, veuillez nous contacter directement en boutique.
